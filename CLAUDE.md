# Portfolio implementation notes

## Current design

This is an explorable island portfolio, built with Next.js 14, React 18, TypeScript, React Three Fiber 8, Drei 9, and Three.js. Keep dependency upgrades coordinated with the React version. Install with `npm install --legacy-peer-deps`.

Visitors scroll down/up between sections, orbit and zoom within an area, select places from a map, and deliberately open readable content from small objects. Ordinary wheel input belongs to section navigation; it must never zoom the camera. The section order is circular: a forward step from the final west shore returns to the overview, while a backward step from the overview returns to the west shore. Zoom uses pinch, explicit buttons, or the focused canvas keyboard controls. The scene is one viewport; there is no document-sized camera track. Keep physical objects at their measured scale and avoid shoreline billboards or an invisible multi-viewport scroll container.

`docs/ISLAND_EXPLORATION.md` records the inspected scene, measured anchors, design decisions, and acceptance checks. `README.md` contains run/check commands.

Wait for scene preparation and `document.fonts.ready`; expose the canvas beneath the departing loader, then enable the interface and arrival only after its exit completes. - `LoadingScreen.tsx` / `LoadingArtwork.tsx` / `loading-progress.ts` / `loading-screen.css`: illustrated arrival screen with CSS-only transform/opacity animation on composited HTML layers. Never restore a per-frame JS progress loop, animated SVG strokes, or inherited progress custom property. Asset progress occupies 0–90%; renderer/font readiness permits 100%. The bar eases independently, with no numeric counter to jump after main-thread work. Keep the explicit loading label, visible activity during renderer/font preparation, and three real stages: `total/loaded/active` distinguish downloading from preparation; only the readiness gate permits arrival. The compass, tides and separate land/cabin/palm HTML layers animate without SVG repaint. Error states pause loops but reveal all one-shot entrance layers. Preserve one-shot transition/timeout completion, errors with `/read` access, and immediate Still/reduced-motion behavior.

Canvas remains at `never` until compilation, then warms three demand-rendered frames before reporting ready. The compositor prepares its overview blur at zero mix while covered, and continuous rendering starts only after the loader exits. Cancel stale generations and frame callbacks on pause, unmount or Strict Mode effect replay. Camera setup must establish the arrival origin or skipped-intro overview beneath the loader while exploration input remains disabled.
- `IslandWeatherDriver.tsx` / `island-weather.ts`: one mutable weather state drives Sunlit, Overcast, Tropical rain and Storm. The driver advances active time at frame priority -110, before the day-cycle subscriber at -100. Cloud cover builds before rain; wetness dries slowly after showers. Share its wind direction, gust, integrated drift, sun, fog and restrained lightning values across consumers; do not start independent weather clocks. Pause for loading, hidden tabs, readers and reading travel. Still/reduced motion settles the selected profile immediately, freezes time, omits rainfall and suppresses lightning. `WeatherControl.tsx` / `island-weather.css` own the compact accessible selector. The cinematic minute callback advances weather and toggles daylight/dusk.
- `IslandDayCycle.tsx` / `day-cycle.ts`: one eased, approximately two-second blend drives scene background/fog, ambient/hemisphere/directional colours and intensities, sky, water, emissive accents and selective bloom. Reverse from the current value without snapping. Apply `setWeatherHorizon` after advancing the blend so background, fog and sky meet at exactly the same colour; weather also shortens fog distance. Pause/resume the blend with the scene; Still and system reduced motion switch instantly.
- `IslandSky.tsx` / `island-sky.ts` / `sky-atmosphere.ts` / `night-sky.ts`: persistent gradient dome with soft clouds, an overcast ceiling and an indigo night atmosphere. Aurora curtains and galactic haze reuse the owned 256px cloud-noise lookup; no raymarching or extra render passes. One point draw contains 1,800 deterministic stars (900 on phones) with varied magnitude/colour and slow shared-time twinkle; phones retain one aurora curtain. The moon uses a second owned 256px albedo lookup with maria/craters, phase shading, earthshine and halo. All celestial effects use the same cloud mask and vanish under dense weather. Correct stars/moon/clouds for the same camera-height horizon depression so they stay in frame at the overview and meet the fog horizon. The overview gaze is [1,5.7,0] to leave room for the sky. Keep clocks on shared weather active time; Still, readers and hidden tabs freeze twinkle and aurora as well as clouds. Dispose both textures and all owned resources. Sun halo stays world-oriented behind the ocean at -11. `createCloudBanks`/`cloud-geometry.ts` remain unmounted compatibility helpers; `cloud-texture.ts` is only for ArrivalClouds.
- `IslandWater.tsx` / `island-water.ts` / `water-depth.ts`: one two-triangle ocean at y=2.08 replaces the flat plane and cloned GLTF transmission-water mesh. Bake sand depth and signed shore distance once into a 256px texture; never render another scene/depth/reflection pass for water. Extend only seabed heights offshore, not rock heights, and fade transparency before the finite model edge. Caustics patch owned sand materials and restore their compile hooks on cleanup. All water/caustic animation shares one clock frozen under reduced motion, Still and pause. Mobile compiles two ripple layers. Preserve underwater fish and skip water raycasting.
- `IslandLighting.tsx` / `island-rendering.ts`: cloud cover dims direct sunlight and shadow intensity while the fill becomes cooler and more diffuse; lightning adds restrained ambient/hemisphere light. Shadow fitting uses only the actual island, with wind padding, never the ocean plane. Desktop maps are 2048 and phone maps 1024. Two sustained phone windows above 22ms average disable shadows until reload; exclude loading, readers, hidden tabs and demand rendering from the measurement. Coarse touch devices retain this budget in landscape.
- `IslandRain.tsx` / `island-rain.ts` / `rain-surface.ts`: two bounded GPU-instanced draws provide slanted rainfall and exposed-surface splashes. A shared 512px top-down map records actual surface heights and conservative shelter; clip each rain fragment beneath roofs, terrain and umbrellas. Splash seeds touch exposed model surfaces; ocean rings belong to the water shader. Desktop uses up to 12,000 streaks/340 splashes, phones 4,600/100, and the latched slow-phone tier 2,200/0. Prepare both materials and the shelter texture beneath the loader using `preparing={!renderReady}` even in clear weather. Still/reduced motion omits rain; clear skies add no rain draws after readiness. No atmosphere raycasts may intercept input. Ref-count the shared map and release owned resources on cleanup/Strict Mode replay.
- `island-wetness.ts` / `island-material-effects.ts`: add restrained darkening and reduced roughness only to exposed sand, rocks and authored building/pier materials on the owned model clone. The rain surface map shields interiors; preserve foliage, furnishings and printed objects. Compose wetness and sand-caustic shader hooks so either cleanup order restores the remaining effect and eventual original hooks. Weather wind drives palm crowns, water ripples and rain; wet weather damps motes, fireflies and campfire accents.
- `IslandSound.tsx` / `weather-audio.ts`: start beach ambience and synthesized wind/rain only on visitor interaction. Smooth gains with the shared weather and camera shelter; sparse lightning schedules distant thunder. Pause all audio for readers/hidden tabs and dispose the Web Audio graph. Still/reduced motion suppresses thunder. Preserve the session sound preference and beach-audio fallback if Web Audio is unavailable.
- `IslandPostprocessing.tsx`: lazy-loaded desktop composer (RPP 2.19.1 for React 18). Keep AO gentle and bloom selection restricted to tagged dusk light meshes, with intensity driven by the shared day cycle. Tilt-shift is confined to daylight overview, capped at 0.035 and fades out through dusk so stars/moon remain sharp. Readers disable the whole composer without reallocating its targets. Release owned passes/targets on unmount, preserving Strict Mode effect replay. Canvas uses Three r184’s supported PCFShadowMap constant; the deprecated PCFSoftShadowMap alias has identical filtering but logs and resets the setting repeatedly.
- `section-scroll.ts`: one section per deliberate wheel gesture, with momentum consumption and blocked reader input. Allow a new gesture to retarget an active flight; do not lock scrolling for the flight duration.
- `cinematic-path.ts` / `CinematicTourControl.tsx` / `cinematic-tour.css`: explicit 360° movie mode with independent procedural curves. Never import section poses or call the section route planner to construct the film. A surveyed rounded corridor passes the covered veranda, side walkway and rear deck; seeded radial/height sweeps explore the beach, west shore and lagoon. Keep the angular coordinate monotonic about [-3,-2], one direction per activation, a .23-unit swept camera clearance, and bounded curvature. Capture the live position/gaze and join ahead with a smooth one-time entrance. Prevalidate multiple curves, then select a different cached curve on successive laps with matching rear-deck tangents. No lap easing, stops, return to the live origin, per-frame allocations or synchronous replanning at joins. Accelerate only once over 1.2 seconds into a 2.7-unit-per-second cruise. Use active frame time for 60-second Daylight/Dusk changes. ## Camera constraints

Keep a stable world-up direction and broad neighborhood framing during exploration. Edit area poses, targets, distance limits, and orbit arcs in `island-data.ts`. Portrait framing adjusts field of view as well as distance. Explicit reading approaches use each printed surface's local up direction and interpolate camera quaternions. Do not call OrbitControls.update during these approaches: its cached world-up and exploration constraints would override the reading orientation.

The guard copies selected house, cabin, pier, terrain, rock, bush, and foliage triangles into an owned world-space BVH. Do not build an index-reordering BVH on shared GLTF buffers. Its weak cache follows the scene model lifetime; the collision geometry is CPU-only and is never rendered. Travel tries a direct segment, then inner/outer graph routes with a heading cost to discourage reversals. Each corner gets a local quadratic curve matching its adjacent segment directions. Accept paths only after offset-ray and sampled-clearance checks; do not fall back to a sharp polyline. Unroutable trips fade to the destination. Orbit movement is rejected if the camera passes below y=2.9 or a tested segment/endpoint is obstructed.

The guard is not complete camera-volume collision detection. Added geometry is not automatically in its static model whitelist. Check the visible framing and relevant orbit envelope whenever poses, materials, or geometry change.

## Model and material rules

`public/island.glb` is the preserved original by Jef Belmans. The app uses `island-optimized.glb`; regenerate it with `scripts/optimize-island.mjs` and its documented external tooling.

The model has baked vertex positions and scaled ancestors. Compute world bounds or inspect vertices when locating a prop; `getWorldPosition()` alone may report an origin rather than the visible center. Move animated semantic nodes under measured pivots instead of rotating a shared material mesh around the origin. In particular, the satellite dish shares a mesh with house details.

Only the scene clone receives the two measured fern offsets near the chalkboard. Cached geometry/textures belong to `useGLTF`; dispose only resources created by the component, including cloned materials and generated print textures.

`M_Plants`, `M_PalmTreeLeaves`, and `M_Torch` atlases contain RGB data without alpha. Their opaque cards are a known source-asset limitation. Raising `alphaTest` cannot recover missing alpha; do not guess destructive color-key masks or remove the canopy to conceal it.

## Interaction and lifecycle

- Sound is on by default but, because browsers block audible autoplay, starts only on the visitor's first interaction (pointerup, touchend, keyup, click or keydown); the audio file is not requested before then. Turning it off persists for the session (`sessionStorage['island-sound-off']`).
- Mobile settings are a header disclosure; keep the footer transparent. Phone map destinations use a named list with 44px targets. Keep antialiasing at capped DPR 1, skip R3F hover raycasts for touch/pressed-pointer moves, and omit floating Html labels on phones. Invisible surface-anchored invitation targets remain tappable, using bounded BVH visibility checks and the same action as their physical object. The area's reading action and physical-object taps remain available.
- Palm leaf crowns use owned local pivots with small phase-shifted gusts; never rotate the shared source model or a trunk with a leaf. Daylight adds a soft sun halo and sparse motes; dusk fades in fireflies and ember flicker. Water highlights belong to the water shader. Fish, gulls, hammock/cards, and fire flicker stop or simplify under reduced motion. The user can also choose Still; system reduced motion takes precedence.
- Pause rendering and animation while the tab is hidden or a reader is open. Use accumulated active time to avoid return jumps.
- Water depth lookup texels must settle to `DEPTH_MIN` before the outer perimeter. Clamping a shallower edge reveals the square texture boundary against open ocean. `check-island-water.cjs` checks two perimeter rings; `check-island-sky.cjs` checks persistent drift, pause/resume, palettes and resource cleanup.
- Keep every atmosphere consumer on the shared day-cycle value and shared weather state rather than independent timers. `check-day-cycle.cjs` covers blend timing, reversal from the current value, pause/resume and instant Still/reduced-motion switching. `check-island-weather.cjs` covers cloud/rain sequencing, reversal, retained wetness and sparse lightning; `check-weather-sky.cjs` verifies matching fog/sky colours, celestial masking, wind/pause and resource cleanup.
- Preserve native dialog focus containment, Escape behavior, focus restoration, and normal internal scrolling. Every reading object uses approach → reading → closing → return. Capture the actual camera position, quaternion, up, target, field of view, and orbit limits; reveal the reader only after arrival. Retrace the travelled route on close or cancellation, restore the saved view, and avoid a second flight to the area's default pose. A cancellation before the first animation frame should simply clear focus state.
- Keep the scene and exploration UI inert through the entire reading sequence. Preserve mounted object invitations so DOM focus can return after the camera does. Block wheel section changes during approach/return, but keep normal internal reader scrolling. Still and system reduced motion skip both travel and reader animation. If an arbitrary exploration pose has no safe approach, open content in place rather than teleporting.
- Keep `/read`, named area buttons, and keyboard navigation usable without finding a tiny 3D target. The seven-Nessie trail is optional.

## Verification

Run `npm run lint`, `npx tsc --noEmit`, `node scripts/check-section-scroll.cjs`, `node scripts/check-magazine-camera.cjs`, `node scripts/check-artifact-cameras.cjs`, `node scripts/check-island-navigation.cjs`, and `npm run build` for relevant implementation changes. Production output is `.next-production`, separate from development `.next`.

`node scripts/check-mobile-camera.cjs` exercises the real controller and OrbitControls with a synthetic render loop: viewport resizing during orbit/travel, close-range interruption, inertia isolation, gradual zoom, collision rollback, and Still. It is a behavior regression check, not a phone GPU benchmark.

`node scripts/check-island-arrival.cjs` checks four actual-model arrival routes, loader timing, repeat/Still overview setup beneath the loader, interruption, navigation handoff, session policy, blocked storage, reduced motion, pause/resume, and a late model. Verify fresh-tab playback, reload skip, the letter reveal, and input-to-skip in the browser as well. Use a fresh browsing session to preview the introduction again; do not add a production replay bypass.

`node scripts/check-loading-lifecycle.cjs` exercises the actual loader/readiness hooks with a deterministic clock: zero-RAF loader motion, monotonic progress, Strict Mode effect replay, error gates, transition/timeout completion, Still/reduced motion, batched texture uploads, compiler target restoration, failures, pause/resume and presentation callbacks. `node scripts/check-scene-readiness.cjs` verifies the underlying generation and rendered-frame gate. These scripts do not measure GPU compilation or browser paint; also inspect first-load, cached-load and error handoffs in the browser.

For weather changes, run `node scripts/check-island-weather.cjs`, `node scripts/check-weather-sky.cjs`, `node scripts/check-island-rain.cjs`, and `node scripts/check-weather-ocean.cjs`, alongside the existing sky, day-cycle and water checks. Rain checks use independent actual-model rays to verify roof shelter, exposed impacts, shader warmup, phone tiers and cleanup. Ocean checks cover shared weather uniforms, wetness/caustic hook composition, source isolation and shared texture ownership. Also inspect every weather mode in daylight/dusk, roofs and veranda shelter, post-rain drying, first rain after loading, sound after interaction, Still and reader/tab suspension on desktop and phone-sized viewports; scripts do not establish rendered appearance or device GPU performance.

`node scripts/check-artifact-hover.cjs` checks whole-object idle pulses, stronger hover, a fixed idle footprint, mouse/touch gating, eased 2% scale, an off-origin transformed pivot, warm material isolation, non-selectable glow geometry, mobile shell budgets, stable frame resources, reduced motion, and cleanup/remount. Check the visible highlight and an actual mesh click in the browser after changing hover rendering.

The geometry script checks static endpoints and all 288 ordered area routes at desktop, two portrait sizes, and a narrow landscape size. It independently samples clearance along each returned path. It does not replace browser verification: visit all map areas, interrupt travel, inspect near buildings/palms, test mobile readers and keyboard tabs, close dialogs with Escape, and exercise reduced motion and loading fallback. Report the checks actually performed rather than treating a successful build as visual acceptance.

`node scripts/check-artifact-beacons.cjs` verifies fixed screen size, bounded visibility rays, occlusion, stable frame resources, inactive/Still states, and 40 real-model views. Also click a beacon in the browser on desktop and a phone-sized viewport and verify the correct reader, return and keyboard label focus.

`node scripts/check-cinematic-path.cjs` checks more than 150,000 actual 60Hz samples across desktop/portrait profiles and 40 live starts. It checks swept clearance, constant cruise speed, heading/gaze continuity, monotonic angular travel, seeded diversity from the same origin, multi-lap joins, immutable snapshots, and real spatial interior/shoreline coverage. Do not require visiting AREAS camera poses or returning to the initial view: that would recreate the section-based tour. The mobile controller check covers tour pause/resume, minute changes, first-pointer takeover, resizing, navigation handoff and Still. Also verify visible playback and restarting from a manually explored view in the browser.
